# Gameshow-Scoreboard-Code
Description:
A Jeopardy game show program. This program mainly tracks scorekeeping for a physical Jeopardy game so that scoring doesn't have to be done manually. This doesn't include the actual Jeopardy questions (those should be on a separate physical board). It also includes a leaderboard where people can see each participating team's ranking and their streak (for how many answers they answered correctly in a row). There is also a fast money page for quick responses to a series of questions that will later be scored and assigned points based on how accurate the responses are.

Usability: 
You can't use this program beyond just scoring. Questions will have to be done on their own. You can test it here: https://github.com/Ibis-glitch/Gameshow-Scoreboard-Code/releases/tag/v1.0

How to Use:
Navigate between the leaderboard, gameboard, and the fast money page. The UI is rather intuitive. For the gameboard, click on the points to assign points to teams.
